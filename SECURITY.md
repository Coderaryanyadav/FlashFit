# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within FlashFit, please follow responsible disclosure:

1. Do **not** open a public issue.
2. Email the core team or maintainers with details of the vulnerability.
3. Include clear steps to reproduce, affected workspaces, and potential impact.

We will review the report, issue a patch, and coordinate release disclosures.
